# CitraComm

Next.js storefront and admin dashboard for Citra Com printing services.

## Features

- Public landing page for printing services and catalog/gallery showcase
- Admin dashboard for overview and product management
- Simple role-based login flow with admin/user credentials
- Data stored locally in browser storage for prototype/demo use

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000
